================================================================================
                    MANUS AI CLONE - USER GUIDE (TERMUX)
================================================================================

Welcome! This guide will help you set up and use your own Manus AI agent on
Android using Termux. No complex coding or API keys required!

--------------------------------------------------------------------------------
STEP 1: INSTALL TERMUX
--------------------------------------------------------------------------------
1. Download and install "Termux" from F-Droid (do NOT use the Play Store version).
2. Open Termux on your phone.

--------------------------------------------------------------------------------
STEP 2: RUN THE INSTALLATION
--------------------------------------------------------------------------------
1. Copy and paste the following command into Termux and press Enter:

   chmod +x install.sh && ./install.sh

2. This will install Python, Node.js, and all necessary dependencies.
3. This might take 5-10 minutes. If asked for [Y/n], always type 'Y'.

--------------------------------------------------------------------------------
STEP 3: START THE AGENT
--------------------------------------------------------------------------------
1. Type this command and press Enter:

   ./start.sh

2. LOOK FOR THIS LINE: "YOUR API KEY IS: [ABC-123]"
3. COPY that code! You will need it to login to the Web UI.

--------------------------------------------------------------------------------
STEP 4: OPEN THE PREMIUM WEB UI
--------------------------------------------------------------------------------
1. Open Chrome or any browser on your phone.
2. Go to: http://localhost:8000
3. Paste your "Access Key" and click "Sign In".
4. You are now in the Manus Dashboard!

--------------------------------------------------------------------------------
STEP 5: CHOOSE THE "BRAIN" (AI PROVIDERS)
--------------------------------------------------------------------------------
Manus uses several free AI providers (Gemini, ChatGPT, Blackbox, etc.)
automatically via the g4f engine.
1. Go to Manus Web UI -> Settings.
2. Set "AI Engine Provider" to your preferred brain (e.g., Gemini or Blackbox).
3. Click "Save Changes".

--------------------------------------------------------------------------------
STEP 6: CONFIGURE TELEGRAM (REMOTE ACCESS)
--------------------------------------------------------------------------------
1. Get a "Bot Token" from @BotFather on Telegram.
2. Get your "User ID" from @userinfobot.
3. In Manus Web UI -> Settings:
   - Paste your Token.
   - Add your User ID to the whitelist.
4. Save and RESTART Termux (Ctrl+C and ./start.sh).
5. Now you can chat with Manus directly on Telegram!

--------------------------------------------------------------------------------
STEP 7: USING THE AGENT
--------------------------------------------------------------------------------
- CHAT: Type "Message Manus..." in the bottom bar.
- FILES: Click the "+" button in the chat bar to upload files/photos.
- MISSION: Manus will THINK (Blue bubbles), ACT (Run commands), and finish!

--------------------------------------------------------------------------------
SAFETY & MAINTENANCE
--------------------------------------------------------------------------------
- Update: Run `./update.sh` to get new features.
- Restart: If it gets stuck, press Ctrl+C in Termux and run `./start.sh` again.
- Privacy: Never share your API key or data/config.json file.

Enjoy your autonomous AI assistant!
================================================================================
